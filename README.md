# Hommie

타이핑과 클릭으로 함께 자라는 Windows 트레이 친구입니다.

[최신 버전 다운로드](https://github.com/5ooooodw-cpu/hommie-releases/releases/latest)

Windows 10/11 · .NET Framework 4.8 · 관리자 권한 불필요

## 처음 시작하기

릴리스의 Hommie-버전.zip을 개인 폴더에 풀고 Hommie.exe를 실행하세요. 육성 기록은 실행 파일 옆 data 폴더에 저장됩니다.

## 기존 친구 이어 키우기

0.8.1 이하라면 트레이 메뉴에서 완전히 종료한 뒤 새 Hommie.exe만 기존 폴더에 교체하세요. 기존 data 폴더를 유지해야 같은 친구로 이어집니다.

## 자동 업데이트

0.9.0부터 실행 후 약 15초, 이후 6시간마다 새 버전을 확인합니다. 파일을 내려받아 서명과 무결성을 검사하고, 친구 창과 업데이트 창이 접혀 있을 때 저장 후 다시 시작합니다. 설정 → 앱 업데이트에서 직접 확인·적용하거나 자동 확인을 끌 수 있습니다.

다운로드·검증에 실패하면 기존 버전을 유지합니다. 새 앱이 시작 직후 종료되면 이전 실행 파일로 복구합니다. 인터넷이 끊겨도 육성 기록은 이 PC에 남습니다.

이 저장소는 실행 파일·사용 안내·업데이트 정보를 배포합니다. 육성 데이터, 입력 내용, 소스코드, 서명 개인키는 포함하지 않습니다.
