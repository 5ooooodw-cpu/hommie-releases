# Hommie

타이핑과 클릭으로 함께 자라는 Windows 트레이 친구입니다.

[최신 버전 다운로드](https://github.com/5ooooodw-cpu/hommie-releases/releases/latest)

Windows 10/11 · .NET Framework 4.8 · 관리자 권한 불필요

## 0.10.1 자동 시작

- 처음 친구 화면을 열면 Windows 로그인 시 자동 시작할지 한 번 묻습니다. **동의한 경우에만** 현재 Windows 계정에 등록합니다.
- 직접 실행할게요·닫기·Esc를 선택하면 등록하지 않고 선택을 기억합니다. Enter도 자동 동의하지 않습니다.
- **설정 → 자동 시작** 또는 **트레이 메뉴 → Windows 자동 시작**에서 언제든 켜고 끌 수 있습니다.
- 자동 시작하면 창을 띄우지 않고 트레이에서 조용히 실행합니다. 이미 실행 중이라면 중복 실행하지 않습니다.
- 등록한 앱을 다른 폴더로 옮겨 실행하면 경로를 갱신합니다. Windows에서 직접 꺼 두거나 제거한 등록을 임의로 되살리지 않습니다.
- 선택은 캐릭터 기록과 별도로 보관하므로 새 알을 받거나 기록을 복원해도 유지됩니다.

## 0.10.0 성장 업데이트

- 부화: 누적 60 XP + 실제 활동 10분.
- 아기 → 성장: **알부터 누적 실제 활동 2시간 + 훈련**.
- 성장 → 최종: **알부터 누적 실제 활동 12시간 + 훈련**.
- 부화 후 진화에는 일수·XP 제한이 없습니다. XP·재료 보상 한도는 유지합니다.
- 훈련은 배움/탐험 루트 첫 진화 10점·최종 30점, 동행 루트는 두 훈련 각각 5점·최종 각각 15점입니다. 시간과 훈련은 진화 후에도 이어집니다.
- 각 성장 구간 25·50·75%마다 새 몸짓이 열리고, 실제 활동 약 20~30분마다 작은 우연이 찾아옵니다. 아기·성장·최종 21종 모두 적용합니다.
- 반응 구경 → 성장 몸짓 / 작은 우연에서 무료로 감상할 수 있습니다. 사건을 놓쳐도 불이익은 없습니다.
- 잠금·절전·종료·일시정지와 5분 이상 입력 없는 시간은 제외합니다. 키를 계속 누르는 반복 입력으로 활동 시간을 연장할 수 없습니다.

**기존 친구를 초기화할 필요가 없습니다.** 누적 시간·훈련·재료·도감을 그대로 이어가고, 조건을 채워도 진화는 직접 선택합니다. 미발견 모습과 이름은 계속 ???입니다.

## 처음 시작하기

최신 릴리스의 Hommie-버전.zip을 개인 폴더에 풀고 Hommie.exe를 실행하세요.

0.9.1부터 육성 기록은 Windows 사용자별 `%LOCALAPPDATA%\Hommie\data`에 저장됩니다. 같은 PC·같은 Windows 계정에서는 앱을 다른 폴더로 옮겨도 같은 친구를 이어갑니다. 다른 PC와 자동 동기화되지는 않습니다.

알은 무작위로 받아요. 0.9.1부터 이슬알은 슬라임, 솜털알은 고양이, 코어알은 로봇으로 확정 부화합니다. 이미 부화한 친구는 그대로 유지합니다.

## 기존 친구 이어 키우기

0.9.0·0.9.1 사용자는 기존 친구가 들어 있는 호미를 켜고 **설정 → 앱 업데이트 → 지금 확인**을 누른 뒤 창을 접으면 됩니다. 업데이트 후 기존 data 기록을 고정 저장 위치로 가져오고, 원본도 보관합니다.

0.8.1 이하라면 트레이 메뉴에서 완전히 종료한 뒤 새 Hommie.exe만 기존 실행 폴더에 교체하세요. 처음 이전할 때 기존 data 폴더를 읽습니다.

이미 다른 폴더에서 새 알이 나타났다면 최신 버전의 **설정 → 저장과 복구 → 이전 기록 가져오기**에서 원래 폴더의 `data\pet.json` 또는 `pet.json.bak`을 선택하세요. 이름·XP·날짜를 확인하고 가져오며, 현재 기록도 복구용으로 백업합니다. 두 기록을 합치지는 않습니다.

날짜가 바뀌면 오늘의 입력·보상 통계만 새로 시작하고 친구·누적 XP·재료·도감은 유지합니다.

## 자동 업데이트

0.9.0부터 실행 후 약 15초, 이후 6시간마다 새 버전을 확인합니다. 내려받은 파일의 서명과 무결성을 검사하고, 친구 창과 업데이트 창이 접혀 있을 때 저장 후 다시 시작합니다. 설정 → 앱 업데이트에서 직접 확인·적용하거나 자동 확인을 끌 수 있습니다.

다운로드·검증에 실패하면 현재 버전을 유지합니다. 인터넷이 끊겨도 육성 기록은 PC에 남습니다. 저장 파일과 백업을 모두 읽지 못하면 새 알로 덮어쓰지 않고 원본을 보호합니다.

이 저장소에는 실행 파일·사용 안내·업데이트 정보만 배포합니다. 육성 데이터, 입력 내용, 앱 소스코드, 서명 개인키는 포함하지 않습니다.
