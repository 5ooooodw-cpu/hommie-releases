# Hommie

타이핑과 클릭으로 함께 자라는 Windows 트레이 친구입니다.

[최신 버전 다운로드](https://github.com/5ooooodw-cpu/hommie-releases/releases/latest)

Windows 10/11 · .NET Framework 4.8 · 관리자 권한 불필요

## 처음 시작하기

최신 릴리스의 Hommie-버전.zip을 개인 폴더에 풀고 Hommie.exe를 실행하세요.

0.9.1부터 육성 기록은 Windows 사용자별 `%LOCALAPPDATA%\Hommie\data`에 저장됩니다. 같은 PC·같은 Windows 계정에서는 앱을 다른 폴더로 옮겨도 같은 친구를 이어갑니다. 다른 PC와 자동 동기화되지는 않습니다.

알은 무작위로 받아요. 0.9.1부터 이슬알은 슬라임, 솜털알은 고양이, 코어알은 로봇으로 확정 부화합니다. 이미 부화한 친구는 그대로 유지합니다.

## 기존 친구 이어 키우기

0.9.0 사용자는 기존 친구가 들어 있는 호미를 켜고 **설정 → 앱 업데이트 → 지금 확인**을 누른 뒤 창을 접으면 됩니다. 업데이트 후 기존 data 기록을 고정 저장 위치로 가져오고, 원본도 보관합니다.

0.8.1 이하라면 트레이 메뉴에서 완전히 종료한 뒤 새 Hommie.exe만 기존 실행 폴더에 교체하세요. 처음 이전할 때 기존 data 폴더를 읽습니다.

이미 다른 폴더에서 새 알이 나타났다면 0.9.1의 **설정 → 저장과 복구 → 이전 기록 가져오기**에서 원래 폴더의 `data\pet.json` 또는 `pet.json.bak`을 선택하세요. 이름·XP·날짜를 확인하고 가져오며, 현재 기록도 복구용으로 백업합니다. 두 기록을 합치지는 않습니다.

날짜가 바뀌면 오늘의 입력·보상 통계만 새로 시작하고 친구·누적 XP·재료·도감은 유지합니다.

## 자동 업데이트

0.9.0부터 실행 후 약 15초, 이후 6시간마다 새 버전을 확인합니다. 내려받은 파일의 서명과 무결성을 검사하고, 친구 창과 업데이트 창이 접혀 있을 때 저장 후 다시 시작합니다. 설정 → 앱 업데이트에서 직접 확인·적용하거나 자동 확인을 끌 수 있습니다.

다운로드·검증에 실패하면 현재 버전을 유지합니다. 인터넷이 끊겨도 육성 기록은 PC에 남습니다. 저장 파일과 백업을 모두 읽지 못하면 새 알로 덮어쓰지 않고 원본을 보호합니다.

이 저장소에는 실행 파일·사용 안내·업데이트 정보만 배포합니다. 육성 데이터, 입력 내용, 앱 소스코드, 서명 개인키는 포함하지 않습니다.
